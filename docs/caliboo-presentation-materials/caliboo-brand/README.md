# Caliboo ロゴキット

キャリブレーション型教育ツール Caliboo のワードマークとアプリアイコン。日本語の正式表記は「キャリブー」です。

| 用途 | ファイル |
|---|---|
| 資料のタイトル・印刷 | [横長 SVG](caliboo-wordmark.svg) |
| スライドや文書への画像挿入 | [横長の透過 PNG・2190 × 685 px](caliboo-wordmark.png) |
| アプリアイコン・編集 | [正方形 SVG](caliboo-app-icon.svg) |
| 丸角タイルが必要な場所 | [正方形 PNG・1024 × 1024 px](caliboo-app-icon.png) |
| 角丸マスクをアプリ側でかける場所 | [角まで不透明な PNG・1024 × 1024 px](caliboo-app-icon-opaque.png) |
| 用途、余白、配色の見本 | [A4 横・1 ページのガイド](caliboo-logo-guide.pdf) |

- **造形:** C の左上にラベンダーの博士帽と黄色い房。語尾の二つの o はつながるピーチ色の鼻になり、二つの濃い楕円が文字の内側と鼻孔を兼ねます。字形はパスで作られており、外部フォントや画像は不要です。
- **色:** ミント `#9ADBC9`、ピーチ `#F5A9B8`、ラベンダー `#C8B9E8`、バター `#F6CE78`、インク `#214F49`、ミルク `#FFFCF6`。鼻孔は `#813E51`。
- **配置:** ワードマークの周囲に文字高の約 1/5 の余白をとり、文字・罫線・キャラクターに重ねないでください。白またはミルク色の地に、縦横比を保って置きます。印刷幅は 35 mm 以上、画面は 120 px 以上が目安です。アイコンは 32 px 以上を推奨します。
- **紙面:** 小見出しと本文には濃いインク色と可読性の高い日本語ゴシック系書体を使用。パステルは背景・図形・アクセントにとどめ、QR は白地に濃色で置いてください。
- **アクセシビリティ:** 隣に「Caliboo」の文字がなければ代替テキストは「Caliboo（キャリブー）」。同じ語を隣で読み上げる場合は画像を装飾扱いにします。
