# 発表原稿をCodexでレビューする

このブランチをローカルにチェックアウトし、Calibooを信頼済みプロジェクトとして開く。プロジェクト直下で新しいCodexセッションを開始し、次を貼り付ける。

> docs/caliboo-presentation-script.md を caliboo_presentation_reviewer の独立した3セッションでレビューしてください。1つ目は仕様の正確さ、2つ目は経営層・部長・情シスの判断材料、3つ目は毎分300字・10分上限での抑揚と時間です。同じ版の原稿を渡し、先の指摘は他のセッションに渡さず、最後に重複をまとめてください。

実際の読み上げも確認したい場合は、次の指示を加える。

> 3つ目のセッションでは、日本語音声で原稿本文を通読するリハーサルを行い、音声ファイルの再生時間を実測してください。可能なら音声を聴いてスピード・間・抑揚・聞き取りやすさを確認し、別途必要な操作時間を加えて10分以内か判定してください。音声生成・聴取ができない場合はその旨を明記し、字数からの推定は実測と区別してください。

合成音声による所要時間はあくまでリハーサルの実測であり、当日の本人の発表時間を保証するものではない。本文の字数、音声の実測時間、音声外の操作時間、合計時間、残りの余裕を記録する。

設定ファイルは `.codex/agents/caliboo_presentation_reviewer.toml`。モデルは固定せず、Astra 6.2を利用できる環境では親セッションで選択する。エージェントの権限は親セッションに従う。レビュー時は親を読み取り専用にすると、原稿の書き換えも防げる。CLIでは `/subagents` で別々のレビューを確認できる。
