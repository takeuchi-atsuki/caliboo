# 個人別の誤答復習と間隔学習

GitHub #7、ユーザー承認済みPL-7に対応。分野内ランダム出題から、本人の解答履歴と復習期限を使う出題へ変更する。

## 仕様

- ユーザー×問題の解答（選択肢・正誤・日時）を記録し、別テーブルに累積回数・連続正解数・直近の正誤・次回復習時刻を保存する。正解済み件数は既存のQuizSuccessで一度だけ数え、再回答でも達成率を重複加算しない。
- 誤答は連続正解数を0にし、10分後を復習時刻にする。正解の復習間隔は連続回数に応じて1日・3日・7日・14日・30日（以後30日）。UTCの時刻で比較する。
- 出題は分野で絞り、直前の問題を除外してから、期限到来した誤答、期限到来した正解、未解答、その他の順で選ぶ。期限到来分は古い期限を優先。同順位はランダムとし、将来期限だけの場合は早い期限を優先する。除外で問題がなくなる場合は直前の問題も使う。
- 旧QuizSuccessしかない問題は正解済みとして扱い、未解答より後で復習に回す。過去の解答時刻や履歴を捏造して移行しない。既存の進捗値を起動時にリセットしない。
- 画面は「誤答の復習」「復習のタイミング」「新しい問題」「練習」の出題理由を示す。正解・解説は従来どおり解答後のみ返す。他の利用者の履歴を参照しない。
- 不正な問題ID・選択肢では履歴も進捗も更新しない。採点・履歴・復習予定・達成率を同じトランザクションで保存し、失敗時に部分保存しない。

!NOTE: 間隔は研修向けの初期ルールであり、記憶定着への最適性を実測したものではない。直前の同一問題抑制を優先するため、誤答直後は別問題を挟み、期限到来後に復習する。候補が1問の場合は学習を継続できることを優先する。

## 検証

本人分離、時刻を固定した期限前後、誤答と正解の優先度、間隔の進展と誤答リセット、分野と連続同問抑制、1問だけの分野、過去の正解済み・進捗との互換、再回答の非重複集計と再起動後の保持を確認する。


## 履歴の保持

出題の取得だけでは履歴を増やさない。各解答POSTを学習イベントとして保存し、過去のイベントは上書きしない。SQL式で回数と連続正解を更新する。達成率は「過去に正解した問題の割合」を維持し、誤答では減らさず復習予定を更新する。旧正解済みだけの問題は「その他」の先頭で練習に回し、新たに解答すると復習予定を作る。
