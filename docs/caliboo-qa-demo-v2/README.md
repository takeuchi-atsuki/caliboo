# Caliboo 質疑応答デモ v2（汎用的な強みの見出し）

架空の新入社員が2日分のSQLite演習を日報として記録。**日報原文の実提出 → アプリの解析待ちジョブ → 独立Codex AIの実解析 → 取込 → 講師ロールの模擬確認・承認 → 本人画面**を現行Calibooで再現する。

旧版と異なり、作業名・具体的行動をそのまま強みの見出しにはせず、他の業務にも応用しやすい能力名を見出しとする。具体的な行動・強みと解釈した理由・今回の観測範囲・次の取り組みは詳細へ残す。本人の能力の高低や熟達を断定しない。

## 90秒で見せる流れ

1. 新入社員画面の日報で架空の日報を入力・提出する。
2. 解析待ち状態を確認し、収録済みの実AI出力を取込（再推論ではない）。今回の独立AIはCodex上で解析し、追加の有料APIは利用していない。
3. 講師ロールとして、強み画面で対象者を選択し、候補の根拠と解釈・範囲を展開する。現行仕様では修正・見送り・承認が可能。架空アカウントで承認を模擬操作する。
4. 新入社員画面のホーム/強みに承認済みの候補が表示される。短い能力名で全体を捉え、詳細で具体的な根拠と成長のヒントを確認する。

実機の準備が難しい場合は同梱の実画面PDFを使う。Web上の静的体験版・収録済みの資料は実機操作を再現したものであり、リアルタイムの生成AIや永続化は別。

## ローカル再現

Python 3.12以降とNode/npm、Calibooの開発依存がインストールされた環境を使用。既存の開発サーバーの停止後、リポジトリルートで実行する。

```bash
SCRIPT="$PWD/docs/caliboo-qa-demo-v2/replay_demo.py"
STATE="$HOME/caliboo-qa-demo-v2-1126"  # 今回のための未作成ディレクトリ
python "$SCRIPT" prepare --repo "$PWD" --state "$STATE"
python "$SCRIPT" serve --state "$STATE"
```

- `prepare` : 通常DBとは独立した新規デモDB、ランダムな講師・新入社員の認証情報を作成。
- `serve` : http://127.0.0.1:5173/ のループバックでのみ起動。外部公開はしない。manual provider のためアプリから外部推論APIは呼ばない。
- 次のコマンドは別ターミナルで同じ仮想環境と変数を定義して実行。

```bash
python "$SCRIPT" seed --state "$STATE"
# 上記は前日の日報だけを実APIで投入。当日分をUI入力・提出する。
# 事前に2件とも投入する場合は seed --both を使う。
python "$SCRIPT" replay --state "$STATE"
python "$SCRIPT" verify --state "$STATE"
```

`replay` は日付以外の材料が収録済み入力と一致する場合に限り、独立Codexが今回実際に生成した応答を取込する。新たなAI推論はしない。講師確認前は本人画面に候補が表示されない。デモの講師役で承認し、新入社員に切り替えてホーム・強み画面を表示する。終了はサーバー端末でCtrl+C。個人情報、実日報や既存DBをこの手順へ混入しない。

## 注意事項

- manual実機のAI推論はアプリ外のCodex独立エージェントに限定。追加の有料API利用なし。
- 候補の説明・根拠・観測範囲・ヒントが機構として表示できることを確かめるデモで、実日報に対する精度検証ではない。AIの確信度は能力点・正答率ではない。
- 現行の本人画面では原文引用の展開欄を表示しない。実運用のアクセス管理は別途確認する必要がある。
- 人事査定・選抜に用いることを意図していない。
