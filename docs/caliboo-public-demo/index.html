体験版とCaliboo本体の違い

この体験版

固定された架空日報と事前生成結果のみ。個人情報を入力する機能や保存機能はありません。再読み込みで初期状態に戻ります。

本体（開発中）

日報・課題等の記録、強み候補の生成・講師承認、本人への表示、およびOJT・資格勉強・課題演習を実装。運用条件は別途検証が必要です。
