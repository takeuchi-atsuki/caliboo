# フロントエンド手動テストケース

!NOTE: フロントエンドの自動単体テスト基盤(Vitest + Testing Library)を導入した(2026-09-11)。`src/lib`配下のAPIクライアントや`features/*/use*.ts`等のカスタムhooksのうち、ロジックを持つファイルは自動単体テストの対象とし、デザインカンプの再現確認(レイアウト・見た目)は引き続き本チェックリストによる手動(Playwright代行)確認で担保する。`docs/test-perspectives.md`のうち画面操作を伴う観点をここでチェックリスト化する。

## パスワード変更・再設定（issue #23）

1. ログイン画面の「パスワードを忘れた場合」から再設定画面を開き、説明と入力欄が表示されることを確認する。
2. 講師でユーザー管理を開き、対象者のコードを発行する。コードは発行直後にだけ見え、別ユーザーを選び直すと再表示されないことを確認する。
3. 正しいコードで新パスワードを設定し、古いパスワードでログインできず、新しいパスワードでログインできることを確認する。
4. ログイン中にパスワードを変更し、ログイン画面へ戻ることを確認する。別端末で開いていたセッションも失効することを確認する。

## 課題ワークスペース（issue #24）

1. 新入社員で課題詳細を開き、`main.js`に`console.log("hello")`を入力して「実行」または`run`を使い、ターミナルに`hello`が表示されることを確認する。
2. `help`、`ls`、`cat main.js`、`clear`を入力し、案内・ファイル名・コード・出力消去がそれぞれ動くことを確認する。
3. 「コードを回答欄へ反映」を押し、内容が提出欄へ入ることを確認する。ページ再表示後も同じタブではコードが復元され、別利用者・別課題には表示されないことを確認する。
4. 無限ループで2秒後に停止し、長い出力も100行で停止することを確認する。コード内からアプリのCookieや保存領域へアクセスできず、ネットワーク通信もできないことをブラウザの開発者ツールで確認する。
5. ログアウトして再ログインした後、ワークスペースの一時保存が消えていることを確認する。

## 実行前提

```bash
bash ./devel/setup.sh       # 依存パッケージのインストール(ホストでの初回・依存の変更時。Dev Containerでは作成時に自動実行)
bash ./devel/dev-server.sh  # バックエンド(:8000)とフロントエンド(:5173)をまとめて起動
```

詳細は`devel/README.md`を参照。

`dev-server.sh`はCtrl+Cで両サーバーを同時に止める。バックエンドだけを停止する項目(44・45・47)は、2つのターミナルで個別に起動し、バックエンド側だけをCtrl+Cで止める。

```bash
# ターミナル1: バックエンド
cd backend && python3 -m uvicorn caliboo_api.main:app --reload --port 8000

# ターミナル2: フロントエンド
cd frontend && npm run dev
```

`http://localhost:5173/home` をブラウザで開く。
