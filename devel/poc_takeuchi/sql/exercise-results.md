## inner_join

INNER JOINは提出済み4組だけを返し、未提出4組を落とす。

期待値:

```json
[
  [
    10,
    1,
    201
  ],
  [
    10,
    2,
    202
  ],
  [
    11,
    1,
    203
  ],
  [
    11,
    3,
    204
  ]
]
```

実測値:

```json
[
  [
    10,
    1,
    201
  ],
  [
    10,
    2,
    202
  ],
  [
    11,
    1,
    203
  ],
  [
    11,
    3,
    204
  ]
]
```

照合: 成功

    10,

  ],
  [

## foreign_key

存在しない利用者への提出は外部キー制約で拒否され、件数は変わらない。

期待値:

```json
{
  "error": "FOREIGN KEY constraint failed",
  "count": 4
}
```

実測値:

```json
{
  "error": "FOREIGN KEY constraint failed",
  "count": 4
}
```

照合: 成功

## rollback

有効な追加をBEGIN内で実施後、ROLLBACKで件数と行を元に戻す。

期待値:

```json
{
  "before": 4,
  "during": 5,
  "after": 4,
  "new_row": 0
}
```

実測値:

```json
{
  "before": 4,
  "during": 5,
  "after": 4,
  "new_row": 0
}
```

照合: 成功
