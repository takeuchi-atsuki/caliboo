# 竹内・実作業による強み解析 PoC

AIエージェントが3Dモデル制作、SQLite演習、ユーザー一覧スクリプト開発を実行し、Calibooの課題提出・日報・フィードバック・強み表示へ接続する実行記録。

[初回の成果報告](../../docs/poc-takeuchi-2026-09-29.md) に確認先・解析比較・検証結果をまとめた。通常解析ジョブ9、PoC比較run `run_0001` として保存し、初回は竹内の強み画面・ホームに4候補を表示した。能力と仕事上の性格傾向へ改善する追加課題は[profile/README.md](profile/README.md)に記録する。

## 成果物

- [3Dモデル](model/README.md): 再生成可能なOBJ/MTLと回転ビューア。
- [SQLite演習](sql/README.md): 6つのSQLと制約・ロールバックの8項目を実行し、期待値と実測値を照合。
- [ユーザー一覧Pythonスクリプト](users/README.md): 実APIの登録アカウントを表示し、認証・権限エラーを区別。
- `trace/`: 実際のAPI応答、作業者・講師・レビュー・解析の入出力、画面確認結果。

## 実行方針

講師が課題を配信し、竹内アカウントで成果物を提出する。作業者・講師の3周の記録から日報を生成し、管理職・講師・シニアエンジニアがそれぞれ日報だけをレビューする。3件をFan-inで統合し、要約と原文を保存する。その後、履歴を継承しない別モデルが提出済みの材料を解析する。

!NOTE: ユーザーの指定に従い、作業者は実ファイルを実装・実行できるエージェントとした。スキルの作文だけの模擬作業を、実施済み作業として扱わない。レビューと独立解析には必要な入力だけを渡し、想定の強み・既存解析結果を渡さない。

!NOTE: 講師役の代替と本人画面への可視化まで今回の依頼に含まれるため、候補確認もAI講師として行う。人間による評価実績としては登録しない。このPoCは人間の竹内さんの能力を測定したものではなく、AIが実行した作業を材料とする運用フローの検証である。

## 日付

日報の日付はアプリの運用日付に合わせた日本時間の2026-09-29。APIの保存日時はUTCであり、2026-09-28になる場合がある。作業時間帯はエージェントの実行記録から取得し、人間の勤務時間を仮定しない。
